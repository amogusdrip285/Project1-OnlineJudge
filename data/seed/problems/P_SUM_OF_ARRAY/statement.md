Given `n` integers, print their sum.

### Input
The first line has `n` (1 ≤ n ≤ 10^5). The second line has `n` integers, each with absolute
value at most 10^9.

### Output
The sum of the `n` integers.

> The sum can reach 10^14: use a 64-bit integer. With large inputs, read fast
> (`ios::sync_with_stdio(false)` in C++, `sys.stdin.buffer.read()` in Python).

### Example
Input:
```
5
1 2 3 4 5
```
Output:
```
15
```
