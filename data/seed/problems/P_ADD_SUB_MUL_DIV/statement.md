Given two integers **a** and **b**, print `a + b`, `a - b`, `a * b` and `a / b` (integer
division, rounded down), one per line.

### Input
One line with two integers `a` and `b` (0 ≤ a ≤ 10^9, 1 ≤ b ≤ 10^9).

### Output
Four lines: `a + b`, `a - b`, `a * b`, `a / b`.

> `a * b` can be as large as 10^18: use a 64-bit integer (`long long` in C++).

### Example
Input:
```
3 5
```
Output:
```
8
-2
15
0
```
